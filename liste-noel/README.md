# 🎄 La liste de Noël d'Alex

Site vitrine statique : un message vidéo du Père Noël, puis la liste de Noël.

## Structure

```
index.html        → la page
style.css         → le style
script.js         → la vidéo, la liste, la neige
cadeaux.js        → ✏️ LA LISTE DES CADEAUX (seul fichier à modifier)
assets/
  pere-noel.mp4   → la vidéo du Père Noël (à ajouter)
  images/         → les photos des cadeaux
```

## Ajouter la vidéo

Place ta vidéo dans `assets/` sous le nom `pere-noel.mp4`.
Conseil : compresse-la en MP4 H.264, autour de 5 à 10 Mo pour 15 s en 1080p.

## Mettre en ligne avec GitHub Pages

1. Crée un dépôt sur GitHub et pousse tous les fichiers à la racine.
2. Va dans **Settings → Pages**, choisis la branche `main` et le dossier `/ (root)`.
3. Le site sera en ligne sur `https://<ton-pseudo>.github.io/<nom-du-depot>/`.
